# Voice avatar regression tests

Run from the repository root:

```sh
npm install
npm test
npm run test:avatars
npm run build
```

The browser suite uses the installed Google Chrome (`channel: 'chrome'`). If Chrome
is unavailable, install it or change the Playwright configuration to an installed
Chromium channel. The suite starts Vite on port 8080, or reuses a running server.

`tests/avatar/index.html` renders the production `VoiceMode` and `VrmStage` with the
same production styles. It is a Vite development entry and is not an entry in the
production build. The stage harness observes Three.js scenes through
`Scene.onBeforeRender`; no test hooks or global scene references are installed in
the production UI.

The suite covers built-in VRM 1.0/0.x and GLB avatars, gestures returning to rest,
full-body gesture framing, morph bounds, camera modes, pointer rotation, lighting,
GLTF/FBX/OBJ/PMX/PMD imports, ZIP dependencies and Japanese paths, failure recovery,
rapid model switches, GPU resource counts, persistence, removal, close/reopen,
and a 390×844 mobile viewport.

The full `/chat` route test uses an isolated dummy Supabase session and intercepted
HTTP/WebSocket endpoints. It cannot write to a real Supabase account. AI speech playback is exercised with intercepted silent 24 kHz PCM to
check that streaming playback works, lip sync opens the mouth, and the mouth closes
after playback. The test also checks missing API configuration and prevents
accidental browser TTS fallback.
It does not evaluate audible voice quality or microphone recognition.

Fixtures in `fixtures/` are original small geometry/rig fixtures generated by
`generate-fixtures.py`; they are committed so the tests need no Python setup.
Run `python3 tests/avatar/generate-fixtures.py` to regenerate them. These fixtures
exercise parsers and basic bone/morph behavior; they do not represent every
third-party avatar, FBX authoring tool, or complex MMD physics rig.

Screenshots and failure context are written to ignored `test-results/`.

## Real MMD regression sample

The extended MMD suite uses the Japanese Miku PMD sample from three.js r160.
It is downloaded for local testing only, excluded from Git, and never included
in `public/` or the production build. This is not an MIT/CC0 avatar; its license
and readme are fetched alongside it.

```sh
node tests/avatar/fetch-mmd-sample.mjs
npm run test:avatars
```

Without the download, the two real-model cases explicitly skip. With it, all
22 browser cases run. `mmd.spec.ts` checks lowered idle arms, wrist heights,
repeat gestures, frame-to-frame quaternion changes, return to rest, finger curl,
palm orientation toward the camera, and all emotion/speech combinations. It
asserts that wink variants stay zero, mouth weights remain bounded and return
to zero, and eye morphs do not stack past the deformation budget.

`src/lib/mmdAvatar.test.ts` additionally covers rotated bone axes, T/A-pose
calibration, independent finger axes, arm IK isolation, incomplete skeletons,
fullwidth Japanese aliases, bilateral blinking, missing-vowel fallback and
group/leaf morph conflicts. Physics simulation is not installed by these tests.
