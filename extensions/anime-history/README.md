# LimeNote アニメ履歴の移行 v1.1.0（Chrome / Edge）

1. ZIPを解凍し、`chrome://extensions`（Edgeは`edge://extensions`）でデベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」からmanifest.jsonのあるフォルダーを指定する。
2. Prime Video・ABEMA・dアニメストア・ニコニコ動画の視聴履歴、ウォッチリスト、マイリストを開き、拡張機能の「このページの履歴を読み取る」を押す。
3. スクロールやページ送りで続きを表示し、再度読み取る。表示済みの作品を重複除去して最大1,000件まで端末内に保存する。おすすめは除外する。ウォッチリストの追加日・配信日を視聴日時に変換しない。
4. LimeNoteに本人としてログインし、自分の視聴履歴ページ下部の小さな「取り込み」を押す。Annictの照合結果を確認して保存する。拡張機能の「LimeNoteへ移行する」からも転送できる。保存した履歴は全体公開。

更新時は同じフォルダーへ新版を展開して拡張機能画面の再読み込みボタンを押し、LimeNoteのページも再読み込みする。シークレットウィンドウで利用する場合はChromeの拡張機能詳細で「シークレットモードでの実行を許可する」を有効にする。

履歴ページへの入口：Prime Videoはアカウントと設定の「視聴履歴」、ABEMAはマイページの「視聴履歴」または「マイリスト」、dアニメはマイページの「視聴履歴」、ニコニコは「視聴履歴」。対象外の画面では拡張機能に「このサービスの視聴履歴を開く」が表示される。

Cookie・認証情報・動画・非公開APIは読み取らない。常時収集、自動巡回、ポーリングは行わない。LimeNote用コンテンツスクリプトは固定のLimeNoteホストとlocalhost:8080の視聴履歴ページに限定し、ページの取り込み操作時だけ端末内の移行データを送信する。曖昧な作品は自動確定しない。各配信サービスの表示変更で取得できなくなる場合がある。

`npm run build:anime-extension` は `extensions/anime-history.zip` とページ下部から取得する `public/extensions/anime-history.zip` を生成する。`npm run build` でも最新の拡張機能を同梱する。テストは旧・新URL、ABEMAのリンクを持たないカード、PrimeのASIN、dアニメの話数リンク、ニコニコのタイトルDOM、非表示・おすすめ除外、ウォッチリストに対応したフィクスチャで行う。
