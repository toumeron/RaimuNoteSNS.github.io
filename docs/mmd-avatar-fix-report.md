# MMDアバターの制御

共通制御は `src/lib/mmdAvatar.ts` に実装し、ボイスページで必要なときに読み込む。

## 姿勢とジェスチャー

- 左右の腕・肘の位置から待機角を求め、Tポーズ・Aポーズの腕を下ろす。
- 待機角を基準に手振り・両手を上げる動作を構成し、モデルごとのボーン回転軸に対応する。
- 肘・手首・指を補間し、ジェスチャー終了時に待機姿勢へ戻す。
- 指の配置から手のひらの面と曲げ軸を求める。待機時は指を軽く曲げ、手振り時は開いて手のひらを正面へ向ける。
- 制御する腕に関係するIKのみを無効化し、足・髪のIKとMMDのIK/grant更新を維持する。
- 手首まで揃っていない骨格では手振り操作を無効化する。

## 表情と口パク

両目まばたきモーフを優先し、なければ左右一組を使用する。片目のウィンクは自動まばたきに使わない。眉・目・口の標準モーフを選び、各領域の変形量を制限する。グループモーフと構成モーフの重複も抑制する。

まばたき時は目の感情モーフ、口パク時は口の感情モーフを弱める。母音の切り替えを補間し、発話終了後は口を閉じる。「え」がないPMDでは「い」を弱く使う。視線・首の追従には角度制限を設ける。

## テスト

```sh
node tests/avatar/fetch-mmd-sample.mjs
npm test
npm run test:avatars
```

小さなPMX/PMDフィクスチャと [three.js r160のMMDサンプル](https://github.com/mrdoob/three.js/tree/r160/examples/models/mmd/miku) を使う。実サンプルはローカル検証用で、Gitやアプリに同梱しない。ダウンロードしない場合は実モデルのテストをスキップする。

姿勢復帰、指の開閉、骨の回転、表情・口パクの組み合わせ、変形量、NaN、リソース解放を検証する。任意の第三者モデルへの互換性や、髪・衣服の物理演算、VMD再生はこのテストの対象に含まれない。詳細は [アバターの回帰テスト](../tests/avatar/README.md) を参照する。
