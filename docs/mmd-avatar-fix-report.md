# MMD の手・指・表情 修正・検証報告

2026-10-01。ボイスページで利用する MMD 共通制御を修正しました。

## 修正した問題

- 腕の初期姿勢を保存するだけで、会話時の自然な待機姿勢への補正がありませんでした。左右の腕・肘の実際の位置から補正角を求め、Tポーズ・Aポーズのどちらでも腕を下ろします。
- 手を上げる角度の符号と基準がモデルに合っていませんでした。初期姿勢から算出した待機角を基準に、手を振る・両手を上げる動作を構成します。ローカルの回転軸が異なるボーンにも対応します。
- ジェスチャーの肘には開始・終了の補間がかかっていない定数角度がありました。肘・手首・指まで同じ補間量で連動させ、終了時には待機姿勢へ戻します。お辞儀も開始・終了が滑らかになる曲線を使用します。
- 指の制御がなく、手のひらも横を向いていました。指の配置から手のひらの面と指の曲げ軸を求め、待機時には軽く曲げ、手を振る時には開き、手のひらを正面へ向けます。親指は他の指より小さい角度で制御します。
- 腕IKがあるモデルでは会話ポーズと干渉する可能性がありました。制御する腕に関係するIKのみ無効化し、足・髪などのIKは維持します。毎フレームの MMD IK/grant 更新も維持します。
- まばたきと複数のウィンクを同時に駆動していました。両目まばたきモーフを優先し、それがなければ左右一組だけ使用します。片目のみのウィンクは自動まばたきに使いません。
- 表情をMMDの眉・目・口の分類に合わせて選択します。「困る」「怒り」「上」「笑い」「なごみ」「にやり」などの標準的なモーフを使い、涙や複数の代替モーフを一斉に駆動しません。
- まばたき時には目の感情モーフを弱め、口パク時には口の感情モーフを弱めます。各顔領域の変形量を制限し、グループモーフと構成モーフの重複を抑制します。
- 母音の切り替えを滑らかにし、発話終了後は口を閉じます。「え」がないPMDでは「い」を弱く使う代替を用意しました。視線・首の追従も角度制限と補間を加えました。

共通制御は `src/lib/mmdAvatar.ts` に切り出し、ボイスページで必要なときに読み込みます。手首まで揃っていない骨格では手を振る操作を有効にしません。

## 検証

| 検証 | 結果 |
| --- | --- |
| 単体テスト | 55件成功（今回のMMD追加20件を含む） |
| ブラウザテスト | 22件成功（実MMDモデルの2件を含む、2.4分） |
| 本番ビルド | 成功 |
| MMD制御・単体テストの ESLint | 成功 |
| `git diff --check` | 成功 |
| 全体 TypeScript チェック | 既存の `src/data/posts.ts` の18件の型エラーが残る。今回の変更ファイルの型エラーはなし |

前回の小さなPMX/PMDフィクスチャに加え、今回は [three.js r160 の実MMDサンプル](https://github.com/mrdoob/three.js/tree/r160/examples/models/mmd/miku)（MMD同梱の初音ミクPMD）を使用しました。日本語の腕・腕捩・手捩・手首・指・目・足IKと30種類の表情を持つモデルです。モデル本体はローカル検証用としてGit管理外に置き、アプリには同梱していません。

実モデルで、腕を下ろした待機姿勢、片手の手振り、両手を上げる動作、お辞儀、うなずき、反復再生、各フレームの急な回転、指の開閉、手のひらの正面向き、終了後の骨の復帰を検証しました。全6種類の感情と日本語の口パクを組み合わせ、ウィンクの不要な起動、変形量の超過、NaN、発話後の口の開き残り、ブラウザ例外がないことも検証しています。

既存のVRM 1.0・VRM 0.x・GLB、追加形式、ZIP、モデル切り替え、保存と再表示、スマートフォン幅の画面、ボイス画面の起動、音声合成と口パクの接続も再検証しました。

## 再実行

```sh
node tests/avatar/fetch-mmd-sample.mjs
npm test
npm run test:avatars
npm run build
```

実サンプルをダウンロードしない場合、実MMDの2件は明示的にスキップします。テストにアカウントやAIへのリクエストは不要です。

## 検証範囲

使用中の個別MMDファイルはまだ特定できていません。そのモデル独自の骨名・モーフ構成については未確認です。第三者製のPMX実モデルの目視確認も未実施で、PMXの読み込みは元のフィクスチャと共通制御の単体テストで確認しています。髪・衣服の物理シミュレーションやVMDの再生は今回の変更・検証範囲に含みません。本番公開は行っていません。
