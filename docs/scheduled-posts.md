# 予約投稿

保存先は既存の `profile_private_settings.scheduled_posts`（JSONB）です。新規テーブルはありません。予約は所有者だけが閲覧でき、予約時の画像は非公開Storage、投票画像は認証付きCloudinaryに保存します。公開postsには指定時刻の送信処理で初めて追加します。

すべてのポスト作成画面の「予約設定」で日本標準時の年月日・時刻を選び、「確認する」後に「予約する」を押すと保存します。日時は1分後から366日以内、予約は50件までです。モバイルの予約設定は全画面です。予定日時は本文の上に小さく表示します。作成中の予約日時は同じボタンから変更・解除できます。予約一覧画面は設けません。

既存の無料pg_cronで毎分 `publish_scheduled_posts()` を実行します。ブラウザーを閉じても送信され、指定時刻以降の次の実行で投稿します。行ロックと同一トランザクション内の投稿・予約削除で二重送信を防ぎます。投票期間は実際の公開時点から始まります。凍結や削除された引用先などで失敗した予約は削除せず、失敗理由を非公開設定に保持します。所有者用RPCで日時変更・キャンセルできます。

DBマイグレーション `20261013100000_scheduled_posts.sql` は本番適用・履歴記録済みです。予約ジョブの実行成功、既存Botジョブの継続、公開テーブル数37を確認済みです。実際のアカウントの予約や投稿をテスト用に作成していません。GitHub Pagesへの公開・mainへのpushは行っていません。

おすすめは、最初の8回の探索で数件だけ表示され、候補のカーソルがまだ残る場合に追加取得が止まっていた条件を修正しました。表示済みポストがある場合は24回までの探索を許可し、完全に空の探索・実際に進捗がない取得は引き続き止めます。独自の「さらに読み込む」ボタンや定期ポーリングは追加していません。
