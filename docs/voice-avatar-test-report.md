# ボイスページの3Dモデル拡張・動作検証レポート

検証日: 2026年10月1日（日本時間）

標準キャラクターを1件から3件へ増やし、読み込めるモデル形式を4種類から7種類へ拡張しました。モデルの切り替え、姿勢、カメラ、リソースの後始末を改善しています。

## 追加した標準キャラクター

| 表示名 | 形式 | 機能 |
| --- | --- | --- |
| アリア | VRM 1.0 | 口パク、表情、まばたき、4種類のジェスチャー |
| リナ | VRM 0.x | 口パク、表情、まばたき、4種類のジェスチャー |
| ロボット | GLB / RobotExpressive | 待機アニメーション、対応表情、手振り・うなずき・ジャンプ系動作。口パク用モーフはなし |

3件ともモデルを `public/models/` に同梱しました。以前の未同梱の `aria.vrm` とGitHub上の別モデルへの自動フォールバックを置き換え、選んだキャラクターと実際に表示するモデルを一致させています。

アリア・リナはLimeAI内の表示名です。元のモデル名・作者・利用設定はモデル内に保持しています。VRMサンプルはCC0ではありません。利用条件と出典は [LICENSES.md](../public/models/LICENSES.md) に記載しました。RobotExpressiveはCC0です。

## 読み込み対応

| 形式 | 対応内容 |
| --- | --- |
| VRM | VRM 0.x / 1.0。人型ボーン、表情、口パク、まばたき |
| GLB | モデル、対応モーフ、内蔵アニメーション |
| glTF | 自己完結ファイル、またはbin・テクスチャを含むZIP |
| FBX | モデル、対応モーフ、名前を判定できる待機・ジェスチャーのクリップ |
| OBJ | 単独モデル、またはOBJ・MTL・テクスチャを含むZIP |
| PMX / PMD | MMDボーン・対応モーフ・IK/grantランタイム更新 |
| ZIP | 上記形式と関連ファイルの展開。日本語パス、store / deflateに対応 |

アップロードは120MBまで。ZIPは800ファイル・展開後450MBまでです。モデルと参照ファイルはブラウザ内で扱います。単独ファイルが外部のbin・テクスチャ・MTLを参照する場合は、ZIPにまとめる案内を表示します。

ZIPにモデルが複数ある場合はVRM、GLB、glTF、FBX、OBJ、PMX、PMDの順に優先し、同一形式では浅いパスを優先します。意図したモデルを確実に選ぶにはモデル本体を1件だけ含めてください。

GLB/glTFにはDracoとMeshoptのデコーダーを設定しました。この検証では圧縮モデルの全種類は試していません。KTX2など別途トランスコーダーが必要な形式までの対応は保証しません。

## 修正した挙動

- ボイス画面の配置をページ全体のCSSが上書きし、画面や設定ボタンが正しく表示・操作できなくなる問題を修正。
- GLBなどのインポート時はラッパーで位置・大きさを調整し、モデルが持つ回転やスケールを維持。待機は認識できるIdle/Standing/Rest系クリップだけ再生し、先頭の歩行・死亡・攻撃クリップを勝手に再生しない。
- 連続切り替えでは古い取得を中止し、古い読み込み結果と進捗が最新の表示を上書きしない。途中で不要になったモデルも破棄。
- geometry、material、texture、skeleton、MMDランタイム、Blob URL、AnimationMixerを後始末。モデルごとの一時的な表情・ジェスチャー状態も初期化。
- MMDは会話用ポーズを適用する前にランタイムの前フレームの姿勢を戻し、更新を積み重ねない。表情名の数字サフィックス判定も修正。
- 対応ボーン・クリップがないジェスチャーはボタンを無効化。口パク対応の有無も設定に表示。
- モデル本来の姿勢を壊す全体回転による疑似ジェスチャーをやめ、汎用モデルは対応する内蔵クリップで動かす。
- 全身カメラにバンザイ・ジャンプの余白を追加。大きな頭のモデルのアップ表示では頭部サイズとモデルの奥行きを距離に反映。
- IndexedDBの保存はトランザクションの完了を待ち、接続も閉じる。アップロードIDにはUUIDを使い、空ファイルを拒否。

## 検証環境と結果

macOS / Google Chrome 154.0.8037.92。デスクトップ1280×800、モバイル相当390×844。Playwrightで本番のVoiceMode/VrmStageと同じコードを実行し、スクリーンショットも目視確認しました。

| チェック | 結果 |
| --- | --- |
| `npm test` | 35件成功（今回追加34件、既存1件） |
| `npm run test:avatars` | 20件すべて成功（約1分40秒） |
| `npm run build` | 成功 |
| 新しいモデル処理・テストモジュールのESLint | 成功 |
| `tsc --noEmit -p tsconfig.app.json` | 全体は未通過。既存のsrc/data/posts.tsに18件の型不一致。今回のChatPage・avatar各モジュールには型エラーなし |

ブラウザテストは次を検証しています。

1. 標準3モデルの選択、設定保存、再読み込み後の復元。
2. VRM 0.x / 1.0・ロボットの表情、口パク制御、ジェスチャー、終了後の姿勢復帰。
3. 顔アップ・アップ・全身、明暗照明、ドラッグ回転、ズーム。
4. 全身ジェスチャー時の手先・足、各カメラでの頭が画面に収まること。
5. glTF・FBX・OBJ・PMX・PMD、ZIP内のbin・MTL・テクスチャ、日本語フォルダーの読み込み。
6. 破損GLB・破損ZIP・モデルなしZIP・参照bin不足からの復帰。
7. 3周、合計9回のモデル切り替え後に同じロボットのGPU geometry/texture数が増えないこと。遅い取得を挟んでも最新の選択が保たれること。
8. モバイル相当の設定画面、アップロード・保存・削除、ボイス画面の終了と再開。
9. AIチャット本体のルートからボイス画面を開き、標準3モデルを選択できること。認証・Supabase通信は隔離したテストデータを使用し、実アカウントへの書き込みは行っていません。
10. ネイティブ音声合成の開始・終了イベント、発話中の口パク、終了後に口が閉じること。音量0で検証しました。

## 確認範囲の限界

- Safari、Edge、スマートフォン実機の描画は未検証です。390×844はChromeの画面サイズでの検証です。
- マイクの実音声認識、音声の聴感品質、実AIサーバーとの会話往復は今回の3D検証に含めていません。
- FBX・OBJ・PMX・PMDは自作の小さいモデルでパーサーと基本更新を検証しました。配布モデル全件や、複雑なMMDの髪・衣服の物理演算まで保証する結果ではありません。
- 口パク・表情・ジェスチャーはモデル内の対応モーフ・ボーン・クリップに依存します。VRM以外の任意の人型ボーンに対する汎用的なアニメーションのリターゲットは追加していません。
- 本番ビルドは成功していますが、既存の大きなJSチャンクに対する警告があります。全体の型チェックも上記の既存データ定義で未通過です。
- 変更はローカル実装です。公開サイトへのデプロイは行っていません。
