# アカウントレビュー

対象の `public.profiles.review` が `true` のときだけ、プロフィールに「レビュー」タブを表示する。初期値は `false`。有効化はSupabaseのTable Editorで対象ユーザーの行を直接変更する。プロフィール編集・設定画面に切り替えは追加しない。通常のクライアントからのフラグ変更はDBトリガーで拒否する。

レビュータブには平均評価、件数、星1〜5ごとの割合、投稿ボタン、レビュー一覧を表示する。閲覧は未ログインでも可能。投稿といいねはLimeNoteにログインしているすべてのユーザーが利用でき、投稿者側の `review` の値は問わない。評価は整数の星1〜5、タイトルは任意・100文字まで、本文は必須・2000文字まで。画像投稿は提供しない。

同じアカウントへのレビューは投稿者ごとに1件とし、再投稿は自分のレビューを更新する。既存の `LikeButton` を再利用し、レビュー専用の保存処理を渡す。通常のポスト・返信のいいね処理は維持する。

既存の `profiles` に有効フラグを追加し、必要なレビュー本体の保存先として `account_reviews` 1テーブルのみ追加する。星・タイトル・本文・投稿者・日時・いいねを同じレコードで管理する。別のレビュー設定・星の集計・レビューいいねテーブルは作成しない。集計値はRPCで算出し、いいねはログイン中の自分のUUIDのみをDB側で追加・解除する。クライアントに他ユーザーのいいねUUID一覧を返さない。書き込みは専用RPCのみ許可し、投稿者のなりすましや他人のレビュー改変を許可しない。

対象ユーザーの `review` を `false` に戻した場合は、保存済みレビューを残し、表示・新規投稿・いいねを無効化する。対象または投稿者のプロフィール削除時には関連するレビューも削除する。

## 検証

- `node scripts/account-reviews-db-test.mjs`: 管理者のみの有効化、投稿者フラグ不要、入力制限、集計、編集、いいね重複防止、権限、無効化、削除。
- `npx vitest run src/components/post/LikeButton.test.tsx`: 通常のいいね動作およびレビュー保存成功・失敗の表示。
- `npx playwright test -c tests/profile-highlights/reviews.config.ts --workers=1`: デスクトップ、320px、390px、iPhone WebKitでタブの条件表示、横並び、文字の可視範囲、投稿・編集・いいね、画像入力なし、保存失敗時の下書き維持。

ブラウザーテストはAPIフィクスチャを使用する。本番へのレビュー投稿・試験いいねは行わない。GitHub Pagesへの公開は明示的な依頼がある場合だけ実施する。

## 適用状況

2026年10月8日に `20261008230000_account_reviews.sql` のみ本番Supabaseに適用し、マイグレーション履歴に記録した。既存のアプリ用テーブル35個に対してレビュー本体の1個のみを追加（合計36個）。適用後の読み取り検証で有効アカウント0件・レビュー0件、RLS有効、一般ユーザーの直接読み書き不可、匿名投稿不可を確認した。フロントエンドはローカル実装であり、GitHub Pagesには公開していない。
